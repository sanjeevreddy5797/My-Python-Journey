# 💰 Tip Calculator

Today I created a simple **Tip Calculator** using Python. 🐍

In this project, the program asks the user for the **total bill**, how much **tip percentage** they want to give, and how many **people are splitting the bill**.

Then it calculates the tip, adds it to the total bill and finally tells how much each person has to pay.

### Example

```text
----------Welcome to the Tip Calculator----------

What was the total bill? $100
How much tip would you like to give? 10, 12, or 15? 10
How many people to split the bill? 2

The total bill per person is 55.0
```
