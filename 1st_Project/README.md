# 🎸 Band Name Generator

This is my first small project in my Python journey.

Today I learned about `print()`, `input()`, variables and f-strings in Python.

After learning these concepts, I created a simple **Band Name Generator**.

It asks the user:

* The city they grew up in
* Their pet name

Then it combines both and gives a Band Name.

In which city did you grow up?
