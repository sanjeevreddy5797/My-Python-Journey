# 🏋️ BMI Calculator

Today I created a simple **BMI Calculator** using Python. 🐍

In this program, I take the **height** and **weight** from the user and calculate their BMI.

For this project, I learned that the `input()` function gives the value as a **string**, so I need to convert it into a `float` before doing calculations.

The formula I used is:

**BMI = Weight / Height²**

### Example

```text
Enter your height in Meters:
1.75

Enter your weight in Kilograms:
70

Your BMI is 22.857142857142858.
```

Through this small project, I practiced:

* `input()`
* Variables
* `float()` conversion
* Mathematical operations
* f-strings

We can optimize our answer by using 'round()' function by rounding the decimal values upto two places.
